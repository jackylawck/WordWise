# 智識計 | WordWise 💡

> 🛡️ **100% Local. 0% Data Leak. ISO, AI-Act & Privacy-First Architecture.**  
> 一款專為香港文字創作者、Marketer 與辦公室一族打造的零伺服器上傳、100% 離線運行、極速且支援香港在地化語境的文字統計與繁簡轉換工具。

---

## ✨ 核心特色 (Features)

* 🔒 **100% 本地運算與資安 (Privacy & ISO Security)**：所有文字僅在瀏覽器端（Client-side）處理，零伺服器上傳；符合 ISO/IEC 27001 CSP 安全標頭規範，處理公司機密文件最放心。
* 🌐 **雙語介面一鍵切換 (i18n Support)**：內置香港繁體與英文（English）雙語切換，符合 ISO 639-1 國際語系標準。
* 📱 **PWA 離線安裝支援 (Offline PWA)**：支援無縫安裝至 Mac / PC / iOS / Android 桌面，斷網狀態下亦能秒開即用。
* ⚡ **Zero-Dependency 零依賴極速 (Performance)**：採用純原生 JavaScript (Vanilla JS) 打造，CPU 與記憶體佔用極低，無 Supply-Chain 漏洞風險。
* 🇭🇰 **香港在地化繁簡轉換 (HK Localized)**：採用 OpenCC 引擎，精準支援香港繁體字型與詞彙習慣（如：網絡/網絡）。
* 📊 **社群貼文限字數預警 (Social Media Limits)**：即時顯示 X (Twitter)、Threads、Instagram、LinkedIn 專屬權重字數上限、進度條與預估閱讀時間。
* 🧹 **一鍵文字排版清理 (Text Formatter)**：一鍵移除多餘空格、重複空行，大幅提升排版效率。
* ♿ **無障礙設計 (WCAG 2.1 / Accessibility)**：完整支援 ARIA 標籤與螢幕閱讀器，打造高包容性的使用者體驗。
