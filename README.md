# 智識計 | WordWise 💡

> 🛡️ **100% Local. 0% Data Leak. ISO, AI-Act & Privacy-First Architecture.**  
> 一款專為香港文字創作者、Marketer 與辦公室一族打造的零伺服器上傳、100% 離線運行、極速且支援香港在地化語境的文字統計與繁簡轉換工具。

---

## ✨ 核心特色 (Features)

* 🔒 **100% 本地運算與資安 (Privacy & ISO Security)**：所有文字僅在瀏覽器端（Client-side）處理，零伺服器上傳；實施最嚴格 ISO/IEC 27001 CSP 安全標頭（無 `unsafe-inline`、`connect-src 'none'`），處理公司機密文件最放心。
* 🌐 **雙語介面一鍵切換 (i18n Support)**：內置香港繁體與英文（English）雙語切換，符合 ISO 639-1 國際語系標準。
* 📱 **PWA 完全離線快取 (Offline PWA)**：內建 Service Worker 快取機制，支援安裝至 Mac / PC / iOS / Android 桌面，斷網狀態下亦能秒開即用。
* ⚡ **Zero-Dependency 零外部依賴 (Performance)**：採用純原生 JavaScript (Vanilla JS) 與原生 CSS Tokens 打造，CPU 與記憶體佔用極低，完全杜絕 Supply-Chain 漏洞風險。
* 🇭🇰 **香港在地化繁簡轉換 (HK Localized)**：內置詞彙優先的香港在地化繁簡規則引擎，精準支援香港繁體字型與詞彙習慣（如：軟件/軟件、數據庫/數據庫）。
* 📊 **社群貼文限字數預警 (Social Media Limits)**：即時顯示 X (Twitter 官方 280 權重計算法)、Threads、Instagram、LinkedIn 專屬字數上限、進度條與預估閱讀時間。
* 🧹 **一鍵文字排版清理 (Text Formatter)**：支援一鍵或快捷鍵（`Ctrl+Enter`）移除多餘空格、重複空行，大幅提升排版效率。
* ♿ **無障礙設計 (WCAG 2.1 AA / Accessibility)**：完整支援鍵盤焦點提示（`:focus-visible`）、ARIA 標籤與螢幕閱讀器，打造高包容性的使用者體驗。

## 🛠️ 技術棧 (Tech Stack)

* **Architecture:** Vanilla JavaScript (ES6+), HTML5, Native CSS (Design Tokens), Service Worker (Cache-First)
* **UI & Design:** Custom CSS System (No CDN dependency, WCAG 2.1 AA Compliant)
* **Conversion Engine:** Embedded Rule-Based Hong Kong Dictionary Engine
* **Standards & Security:** ISO/IEC 25010 (Quality), ISO/IEC 27001 (Strict CSP), WCAG 2.1 AA, W3C Schema.org
* **Deployment:** GitHub Pages
